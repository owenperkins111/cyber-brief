# Cyber Brief

A short daily cyber security audio briefing, generated each morning by Claude from public reporting and published as a podcast feed.

- **Feed:** https://owenperkins111.github.io/cyber-brief/feed.xml
- `main`: build tools (`tools/`) and archived scripts (`scripts/`)
- `gh-pages`: the served feed and the latest 14 episodes (force-pushed daily, so repo size stays flat)

Voice: Kokoro TTS (offline), voice `af_heart`.
